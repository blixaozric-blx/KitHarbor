# KitHarbor

Kit claiming, previews and an in-game kit editor for Paper/Folia servers.

This repository hosts **release builds only**. Servers running KitHarbor download new versions from
here automatically (see `GENERAL.CHECK-FOR-UPDATES` / `GENERAL.AUTO-UPDATE` in `config.yml`);
the update is installed on the next restart.

KitHarbor is available on BuiltByBit.
